PyDI.utils.llm module

Utilities for unified LLM call logging.

This module provides a small, provider-agnostic logger that captures: - prompts/messages sent to the model - raw responses - timing and basic request params - token usage metadata when available (best-effort across providers)

It is designed to work in both blocking/synchronous call paths and to be reusable across modules. It does not depend on LangChain directly; it only expects a “chat model” object and a “response” object that may expose metadata in a few common places.
