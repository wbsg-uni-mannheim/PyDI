PyDI.normalization.integrations.babel_numbers module

Babel integration for locale-aware numeric parsing.

This module wraps the Babel library to provide: - Locale-aware decimal parsing - Locale inference from numeric strings - Multi-locale parsing attempts

Note: Currency symbol stripping is handled here for numeric parsing purposes. For currency code normalization (EUR, USD, etc.), see the country module.
