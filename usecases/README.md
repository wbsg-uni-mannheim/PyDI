# PyDI - Use-Cases

This folder contains example notebooks implementing data integration pipelines with PyDI. They cover workflows from data profiling over entity matching to data fusion for datasets from 4 different domains.

The PyDI use-case notebooks currently encompass the domains:

1. [Movies](movies_workflow.ipynb)
2. [Companies](companies_workflow.ipynb)
3. [Music](music_workflow.ipynb)
4. [Games](games_workflow.ipynb)
