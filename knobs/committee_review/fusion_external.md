# Fusion Committee — External Literature Search (C3.2)

Targeted external search executed against the query set in [plan_committee_finalization.md §C3](../../plans/plan_committee_finalization.md#c3--fusion-committee). The internal portfolio at [fusion_portfolio.md](fusion_portfolio.md) has **zero directly-reusable anchors** — the truth-discovery and LLM-as-judge axes of the committee have to be built from scratch — so C3.2 carries all the algorithmic weight. Ranking here is by gap-fit × code-maturity, not citation count. The classical 2008-2014 truth-discovery family (TruthFinder, Accu, LTM, CRH, CATD) is included despite being pre-2022 because they remain the canonical reference implementations for every fusion survey in the field (explicitly allowed by the plan).

## Summary

The external search closes 5 of the 6 C3.1 gaps with public code:

- **Gap 1 (truth-discovery / probabilistic fusion)** — TruthFinder (heuristic / classical), Accu (Bayesian point-estimate / classical), LTM (Bayesian Gibbs + multi-truth / classical), CRH (optimisation + heterogeneous / classical), CATD (confidence-interval long-tail / classical), FusionQuery (modern on-demand EM). Six-way coverage — the committee can pick 2-3 of these based on runtime / multi-truth / long-tail trade-offs.
- **Gap 2 (LLM-driven conflict resolution)** — **no external code**. PyDI builds `LLMAsJudgeFusion` from scratch. C3.3 to scope.
- **Gap 3 (entity-aware cross-cell fusion)** — FusionQuery is the closest on-demand match; classical TD methods operate per-cell. For full cross-cell structure reasoning, the LLM-as-judge adapter (Gap 2) is the more natural host.
- **Gap 4 (robust numeric aggregators)** — classical robust statistics (trimmed mean, Huber, weighted median, median-of-means) implemented via scipy / statsmodels; KDEm for multi-modal / heavy-tailed numeric; CRH's continuous-loss variant as a learned-weight option.
- **Gap 5 (source-trust learning from gold)** — Accu's Bayesian posterior supports seeded priors; CRH / CATD / TruthFinder all produce interpretable per-source trust scores that can be initialised from gold labels.
- **Gap 6 (holistic / joint entity-and-value resolution)** — FusionQuery is the only surveyed method that integrates with upstream entity matching at query time; otherwise this remains a multi-step pipeline concern (not a single-fusion-method concern).

Licensing check: Seven of the eight runnable cards (TruthFinder, Accu, LTM, CRH, CATD, KDEm via the KDEm bundle — MIT; FusionQuery — Apache-2.0; robust aggregators — scipy/statsmodels BSD) are permissively licensed. The standalone [joesingo/truthdiscovery](https://github.com/joesingo/truthdiscovery) PyPI package is GPL-3.0 — flag for redistribution in PyDI; the MIT-licensed KDEm port is the safer source for vendoring.

All eight classical / semi-classical methods (rows 1-6, 8) are referenced in the IEEE TBD 2025 survey (row 9) as the canonical TD roster, confirming coverage completeness. The single real hole — LLM-as-judge (row 10) — is an acknowledged open problem in the literature as of 2025.

Scoring and final roster selection are deferred to C3.3.
